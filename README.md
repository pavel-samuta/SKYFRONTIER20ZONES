# SKY FRONTIER: 20 ZONES

Играбельный браузерный прототип: карта из 20 островных зон, управление самолётом, гонки через 6 ворот, грузовые контракты между аэродромами, воздушные бои с противниками, кредиты, улучшения самолёта и отображение других игроков через WebSocket.

## Быстрый запуск: без установки

Откройте `index.html` двойным щелчком в Chrome, Edge или Firefox. Игра сразу работает в одиночном режиме. Прогресс покупок и заработанных кредитов сохраняется в localStorage.

## Настоящий многопользовательский режим

Нужен Node.js 18+ (рекомендуется 22+). Дополнительные npm-пакеты **не требуются**.

В папке проекта выполните:

```bash
node server.js
```

Откройте `http://localhost:3000`. Для игры по локальной сети друзья открывают `http://IP-адрес-компьютера:3000` (необходим доступ к порту 3000). Для игры через интернет разместите Node-сервер на доступном хостинге с HTTPS/WSS, доменом и TLS-прокси. Поддерживаются до 100 подключений по протоколу, но нагрузочное тестирование на 100 игроков не выполнялось.

## Управление

- `W / ↑`: увеличить тягу, `S / ↓`: уменьшить.
- `A / ←`, `D / →`: поворот.
- `Q` и `E`: снизиться / набрать высоту.
- `Shift`: форсаж, `Space`: стрельба.
- `M`: навигационная карта 20 зон, `P`: пауза, `R`: возрождение после потери самолёта.
- Для сенсорного экрана доступны кнопки поворота, тяги и стрельбы.

## Экономика MVP

Контракты оплачиваются по дальности, гонки дают 680 CR плюс бонус за время, каждый сбитый пират приносит 120 CR, победа над пятью пиратами даёт дополнительно 780 CR. Доступны улучшения двигателя, брони и вооружения, а также ремонт. Реальных платежей нет. Счёт — исключительно игровая валюта.

## Архитектура и честные ограничения

```text
index.html
 ├─ Canvas 2D: собственный рендер игрового мира, самолётов, HUD и карты
 ├─ Game simulation: управление, движение, враги, пули, миссии, коллизии
 ├─ Economy: кредиты и улучшения; локальное хранение прогресса
 └─ WebSocket client → /ws (10 обновлений/с)

server.js
 ├─ Node HTTP: отдача страницы и /health
 ├─ WebSocket handshake и RFC 6455 basic frames (без внешних библиотек)
 ├─ Реестр пилотов, snapshots и отправка выстрелов
 └─ Проверка допустимой скорости перемещения, границ и частоты выстрелов
```

Это **реальный сетевой прототип**, а не полноценная авторитетная MMO: другие игроки видны и их выстрелы передаются между браузерами, но сервер пока не подтверждает попадания в других игроков, не хранит кредиты и не обрабатывает платежи. PvE-боты симулируются локально у каждого игрока. Параметр высоты отображается и меняется, но не является полноценной аэродинамической моделью; визуализация — стилизованный 2D-вид сверху, не трёхмерный фотореалистичный симулятор.

Перед выпуском коммерческой игры необходимо перенести экономику, физику и урон на авторитетный сервер, добавить аккаунты, базу данных (например PostgreSQL), ограничение трафика/anti-cheat, платёжного провайдера и аудит безопасности. Для геометрического 3D можно постепенно заменить только клиентский renderer на Three.js/WebGPU, оставив серверный протокол и игровую модель.

## Масштабирование

Предлагаемая схема: auth API → matchmaking → игровые комнаты по 20–40 игроков → authoritative game-loop 20–30 Hz → Redis presence/pubsub → PostgreSQL persistence → магазин с server-side проверкой платежей. 20 зон можно разделить на игровые области со streaming/interest management: сервер рассылает клиенту только находящихся в радиусе видимости игроков.

Игра и визуальные элементы созданы как оригинальный прототип. Не используются чужие игровые модели и изображения. По умолчанию все самолёты вымышленные.
